Do not discard the outbound group session when a full member-list reload leaves
the active member set unchanged. Previously, `receive_all_members` always called
`OlmMachine::discard_room_key` as an MSC4268 precaution, so any full reload — for
example a client restart re-fetching `/members` — rotated the room key and forced a
new outbound session on the next send.
